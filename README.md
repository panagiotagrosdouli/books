# Emma Lk — Fiction for the Curious

An English author portfolio for Emma Lk, featuring 18 original stories across four collections.

## Start here

New to reading? Choose a story premise first: a murder with one clue, memories from the future, or a love caught between myth and humanity. Each introduction leads to Emma’s Wattpad profile.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then select branch `main` and folder `/(root)`. The static portfolio is served from `index.html`; book covers are in `site-source/public/`.

## Source

The `site-source/` folder contains the original Next.js/Vinext source for the ChatGPT Site, including the responsive author portfolio, configuration, and assets.

# My Books

An English author portfolio featuring 18 original stories by Emma Lk.

## Explore

Browse four collections spanning science fiction, mystery, romance, fantasy, and more. Every story links to the author’s Wattpad profile.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then select branch `main` and folder `/(root)`. The root `index.html` is a static portfolio that follows the design of the ChatGPT Site. Book covers are stored in `site-source/public/`.

## Source

The `site-source/` folder contains the original Next.js/Vinext source for the ChatGPT Site, including its app, configuration, and assets.
